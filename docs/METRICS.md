# 指标口径

本页描述 1.1.28 的代码实现。指标有各自的采样窗口，瞬时值不保证与另一个软件逐秒一致。

| 项目 | 实现 |
| --- | --- |
| CPU 总占用 | `GetSystemTimes` 相邻采样的 `(kernel + user - idle) / (kernel + user)`；kernel 已包含 idle。是平均忙碌时间，不是频率归一化 utility。超过 64 个逻辑处理器的处理器组场景未验证。 |
| 最忙逻辑核 | `Processor Information(*)\\% Processor Time`，排除汇总实例，取有效逻辑处理器最大值，包括 SMT。 |
| CPU 频率 | `Processor Information(*)\\Actual Frequency`，详情展示有效逻辑处理器的最小、最大和算术平均值；驱动未提供时不估算。 |
| 内存 | Windows 物理内存状态，非进程提交量。 |
| GPU | `GPU Engine(*)\\Utilization Percentage`。按适配器 LUID、物理引擎归组，同一引擎跨进程累加并限制到 0–100%；总体取最忙引擎，各类别取该类最忙引擎。 |
| GPU 分类 | 3D、计算、复制、视频编码、视频解码；驱动未开放独立计算引擎时显示暂无，不复用 3D 值。默认任务栏关闭计算项，可在菜单选择。 |
| 适配器选择 | 独显通过 NVIDIA NVML UUID / PCI 信息绑定到 Windows 适配器；核显通过 DXCore `IsIntegrated` / `IsHardware` 识别并按 LUID 独立统计。当前选择一块独显和一块核显，不承诺通用多 GPU 支持。 |
| 网速 | `GetIfTable2` / `GetIfEntry2` 物理以太网和 Wi-Fi 接口累计字节的差值除以实际时间；排除虚拟、过滤、回环、隧道接口。B/s 是字节每秒。 |
| 当日流量 | 程序观察到的物理网卡收发增量，按本地日期累计并定期保存检查点。重启进程恢复已保存总数，同一天内，休眠后的单调计数器增量仍会计入；计数器回退或接口变化时重新建立相应基线。不是账单流量，包含局域网，未运行时不能补记。 |
| 磁盘活动 | 有效物理磁盘中最忙磁盘的活动时间比例。 |
| CPU 温度 | AMD Tctl/Tdie，通过独立管理员 helper 和已安装 PawnIO 读取；当前仅 family 19h/model 61h，每 2 秒更新。 |
| 独显温度与显存 | NVIDIA NVML，依赖本机驱动开放对应接口。 |
| 核显温度 | Windows WDDM 同一适配器 LUID 的温度接口，每 5 秒更新。 |
| 硬盘温度 | Windows 原生存储温度查询，每 5 秒更新；任务栏取所有有效传感器最高值，详情保留各盘和传感器编号。 |

采样失败、尚未完成预热、硬件不支持或缺少权限有不同状态；不可用值不伪装成 0。CPU 与核显温度不会互相替代，也不估算未提供的热点、显存或硬盘控制器温度。

与任务管理器比较时，需要对齐刷新间隔、GPU 设备与图表引擎。CPU busy time 与 CPU utility 的定义可能不同；任务管理器界面的实现也随 Windows 版本变化。
